# 공부 노트 — 백엔드를 처음 배우며

이 폴더는 이 저장소를 만들면서 **처음 만나는 것을 전부** 기록하는 곳이다.
코드보다 먼저 읽는다. 프론트엔드(React·TS)에서 이미 아는 것에 붙여서 설명한다.

## 읽는 순서

| 파일 | 무엇 | 언제 읽나 |
|---|---|---|
| [00-왜-서버가-필요한가.md](00-why-a-server.md) | 기획서를 쉬운 말로 다시 쓴 것. 서버·DB·배포가 각각 왜 필요한지 | 지금, 처음 한 번 |
| `01-*.md`, `02-*.md` … | 단계별 수업 노트. 그 단계에서 실제로 만난 문제와 개념만 | 그 단계를 할 때 |
| [glossary.md](glossary.md) | 용어 사전. 항목마다 "만나는 단계"가 적혀 있다 | 모르는 말이 나올 때만 찾아본다. **순서대로 읽지 않는다** |
| [../learning-log.md](../learning-log.md) | 만난 순서대로 한 줄씩. 면접 때 "언제 뭘 겪었나" 색인 | 나중에 |

## 규칙

- 단계마다 브랜치 하나(`feat/NN-slug`) → PR → 본인이 읽고 머지. 문서만 고치는 건 `main`에 바로. (4단계부터, 사용자 요청)

- 개념은 **문제가 터졌을 때** 이름을 붙인다. 미리 외우지 않는다.
- 설명은 항상 "프론트로 치면 ___"이 한 줄 붙는다. 안 붙으면 설명이 덜 된 것이다.
- 한 수업 노트에 새 개념은 최대 둘.
- 모르는 게 나오면 사전에 먼저 항목만 추가하고("아직 안 만남"), 만났을 때 채운다.
